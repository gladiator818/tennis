## 6) Valor Terminal (dos metodologías)

### A) Perpetuidad (Gordon Growth)
- **TV = FCFF_FY5 × (1 + g) / (WACC − g)**
- Supuestos base: **g = [ ]%** (anclado a inflación + crecimiento real de largo plazo, por debajo/igual al PIB nominal de largo plazo).

### B) Múltiplo de salida
- **TV = EBITDA_FY5 × Exit Multiple (EV/EBITDA)**
- Exit multiple basado en comps/precedentes: **[ ]x – [ ]x**

### Enterprise & Equity Value
- **EV = Σ PV(FCFF explícitos) + PV(TV)**  
- **Equity Value = EV − Deuda Neta − Minoritarios + Asociadas + Caja no operativa**  
- **Precio por acción = Equity Value / # acciones diluidas**
